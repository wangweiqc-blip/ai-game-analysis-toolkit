# 本地上游参考

- `mesen-lua.json`：Mesen CE 2.2.1 的 Lua API 数据，来自 `https://github.com/nesdev-org/MesenCE/blob/2.2.1/UI/Debugger/Documentation/LuaDocumentation.json`。
- `ppsspp-websocket.md`：PPSSPP 官方主分支的 WebSocket 调试协议文档，来自 `https://github.com/hrydgard/ppsspp/blob/master/docs/WebSocketDebugger.md`；协议实际能力仍以安装版返回结果为准。
- `thtk-readme.txt`：thtk 主分支说明，来自 `https://github.com/thpatch/thtk/blob/master/README`；安装的二进制为 release 12。
- ndspy 与 splat 的完整源码／文档分别在 `research/ndspy-source/`、`research/splat-source/`。
- Ghidra 完整文档位于 `apps/ghidra/ghidra_12.2_PUBLIC/docs/`；无界面分析参数见该版本 `support/analyzeHeadlessREADME.html`。
- QuickBMS 官方文档随工具保存在 `apps/quickbms/`，脚本位于其 `scripts/` 子目录。

下载与固定版本详见 `toolkit.json` 的 downloads 字段。各上游许可随原始包或源码保留。
